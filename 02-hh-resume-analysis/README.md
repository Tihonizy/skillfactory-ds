# HeadHunter Resume Analysis

Data preparation for a future model that predicts the expected salary of a job seeker on
HeadHunter. The notebook parses and transforms raw resume fields (age, experience, education,
city, relocation and business trip readiness, employment type and schedule), converts salaries
to roubles using exchange rates, explores the data with charts and removes duplicates, missing
values and outliers.

- Notebook: [01_hh_resume_analysis.ipynb](01_hh_resume_analysis.ipynb)
- Interactive charts: [charts](charts)
- Tools: pandas, NumPy, Matplotlib, Seaborn, Plotly
