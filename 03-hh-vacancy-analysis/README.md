# HeadHunter Vacancy Analysis with SQL

An IT recruiting agency plans a model that recommends vacancies to candidates. This project
explores the HeadHunter vacancies database with SQL queries run from Python against PostgreSQL:
vacancies by region, salary ranges, schedules and employment types, employers and their
industries, and a focused look at data science vacancies.

- Notebook: [01_hh_vacancy_analysis.ipynb](01_hh_vacancy_analysis.ipynb)
- Interactive chart: [charts/salary_by_schedule_and_employment.html](charts/salary_by_schedule_and_employment.html)
- Tools: PostgreSQL, psycopg2, pandas, Plotly
